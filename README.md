# Opensource Brewing ข้อมูลความรู้การทำเบียร์แบบเปิด

## ขอสั้น ๆ TL:DR
การทำเครื่องดื่มแอลกอฮอล์ คือการใช้ยีสต์เพื่อเปลี่ยนแป้งหรือน้ำตาลให้กลายเป็นแอลกอฮอล์ 
ชื่อเรียกจะแตกต่างกันตามวัตถุดิบที่ใช้ เช่น
- ทำจากองุ่น เรียกว่า ไวน์ (Wine)
- ทำจากมอล์ต เรียกว่า เบียร์ (ฺBeer)
- ทำจากแอปเปิล เรียกว่า ไซเดอร์ (Cider)
- ทำจากน้ำผึ่ง เรียกว่า หมีด (Mead)
- ทำจากข้าว เรียกว่า สาโท (Sato)

#### ภาพรวมของการทำเบียร์ Overview
เบียร์ประกอบจาก 4 ส่วน คือ มอล์ต ฮอปส์ น้ำ ยีสต์
- มอล์ต (Malt) ข้าวบาเลย์ นำไปทำให้งอก แล้วอบแห้ง
- ฮอปส์ (Hops) คือพิชที่ใส่ในเบียร์เพื่อยืดอายุ เพิ่มความขม และเพิ่มกลิ่นหอม
- ยีสต์ (Yeast) สิ่งมีชีวิตขนาดเล็ก ในที่เราใช้เปลี่ยนน้ำตาลเป็นแอลกอฮอล์

การทำเบียร์แบ่งออกเป็น 2 ส่วนคือ ส่วนร้อน (Hot Side) และส่วนเย็น (Cold Side)
**ส่วนร้อน (Hot Side)**
- แมชชิ่ง (Mashing) เปลี่ยนแป้งเป็นน้ำตาล
- บอยลิ่ง (Boiling) ต้มเพื่อฆ่าเชื้อและไล่กลิ่นอับ
- คูลลิ่ง (Cooling) ลดอุณหภูมิให้เหมาะสบกับยีสต์
**ส่วนเย็น (Cold Side)**
- เฟอเมนท์ (Ferment) หมักด้วยยีสต์เพื่อสร้างแอลกอฮอล์
- โคลแครช (Cold Crash) ลดอุณหภูมิเพื่อแยกตะกอนออกจากเบียร์
- คาร์บอเนชั่น (Carbonation) เพิ่มความซ่าโดยเติมแกส CO2

#### ข้อควรรู้ก่อนทำเบียร์
- การเปลี่ยนแป้งจากมอล์ตให้เป็นน้ำตาล เรียกว่า แมชชิ่ง ทำโดยบดมอลต์แล้วแช่ในน้ำ อุณหภูมิ 60-70 องศา เป็นเวลา 60+ นาที เพื่อให้เอนไซม์ในมอลต์เปลี่ยนแป้งเป็นน้ำตาล
- น้ำหวานจากการแมชชิ่ง เรียกว่า น้ำเวิร์ท (Wort)
- หลังจากแมชชิ่ง เราจะต้มเวิร์ดให้เดือด เพื่อต้มเพื่อฆ่าเชื้อและขจัดกลิ่นอับจากมอล์ต ขั้นตอนนี้เรียกว่า บอยลิ่ง (Boiling) โดยทั่วไปราจะบอยลิ่งเป็นเวลา 60 นาที
- การบอยลิ่ง เราจะนับเวลาถอยหลัง ถ้าเราต้ม 60 นาที เริ่มเดือดนับนาทีที่ 60 จนถึงต้มเสร็จ นาทีที่ 0
- ระหว่างบอยลิ่ง เราสามารถใส่ฮอปส์ เพื่อเพิ่มยืดอายุเบียร์ เพิ่มความขม และเพิ่มกลิ่นหอม โดยในสูตรจะระบุว่าใส่ฮอปส์ จำนวนเท่าไหร่ ที่นาทีที่เท่าไหร่ เช่น ใส่ฮอปส์ 20 กรัม ในนาที่ที่ 10 
- เมื่อถึงนาทีที่ 0 เราจะหยุดให้ความร้อน และพยายามลดอุณหภูมิของเวิร์ทให้เหลือ 20 องศาโดยเร็วที่สุดเท่าที่เป็นไปได้
- การที่เรารีบลดอุณหภูมิ เพราะที่อุณภูมิ 35-45 องศาเป็นอุณภูมิที่เหมาะกับเชื้อแบคทีเรียเจริญเติบโต ซึ่งอาจทำให้เบียร์ออกมาเสียได้
- หลังจากเราลดอุณหภูมิเหลือ 20 องศาแล้ว เราจะถ่ายเวิร์ทลงถังหมัก และเติมยีสต์ เพื่อให้
-
