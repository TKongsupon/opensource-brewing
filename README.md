# Opensource Brewing ข้อมูลความรู้การทำเบียร์แบบเปิด

## ขอสั้น ๆ TL:DR
การทำเครื่องดื่มแอลกอฮอล์ คือการใช้ยีสต์เพื่อเปลี่ยนแป้งหรือน้ำตาลให้กลายเป็นแอลกอฮอล์ 
ชื่อเรียกจะแตกต่างกันตามวัตถุดิบที่ใช้ เช่น
- ทำจากองุ่น เรียกว่า ไวน์ (Wine)
- ทำจากมอล์ต เรียกว่า เบียร์ (ฺBeer)
- ทำจากแอปเปิล เรียกว่า ไซเดอร์ (Cider)
- ทำจากน้ำผึ่ง เรียกว่า หมีด (Mead)
- ทำจากข้าว เรียกว่า สาโท (Sato)

#### ภาพรวมของการทำเบียร์ Overview
เบียร์ประกอบจาก 4 ส่วน คือ มอล์ต ฮอปส์ น้ำ ยีสต์
- มอล์ต (Malt) ข้าวงอก อบแห้ง โดยทั่วไปทำจากข้าวบาร์เลย์และข้าวสาลี แต่อาจใช้ข้าวประเภทอื่น ๆ เช่น ข้าวไรย์ หรือข้าวโอ้ต ก็ได้
- ฮอปส์ (Hops) คือพิชชนิดหนึ่ง เราใช้ส่วนดอกใส่ในเบียร์เพื่อยืดอายุ เพิ่มความขม และเพิ่มกลิ่นหอม
- ยีสต์ (Yeast) จุลินทรีย์ พระเอกที่เปลี่ยนน้ำตาลเป็นแอลกอฮอล์

การทำเบียร์แบ่งออกเป็น 2 ส่วนคือ ส่วนร้อน (Hot Side) และส่วนเย็น (Cold Side)

ส่วนร้อน (Hot Side)
- แมชชิ่ง (Mashing) เปลี่ยนแป้งเป็นน้ำตาล
- บอยลิ่ง (Boiling) ต้มเพื่อฆ่าเชื้อและไล่กลิ่นอับ
- คูลลิ่ง (Cooling) ลดอุณหภูมิให้เหมาะสบกับยีสต์

ส่วนเย็น (Cold Side)
- เฟอเมนท์ (Ferment) หมักด้วยยีสต์เพื่อสร้างแอลกอฮอล์
- โคลแครช (Cold Crash) ลดอุณหภูมิเพื่อแยกตะกอนออกจากเบียร์
- คาร์บอเนชั่น (Carbonation) เพิ่มความซ่าโดยเติมแกส CO2

**แมชชิ่ง (Mashing)**
- เป็นการเปลี่ยนแป้งจากมอล์ตให้เป็นน้ำตาล
- ทำโดยบดมอลต์ แล้วนำไปแช่ในน้ำที่อุณหภูมิ 60-70 องศา เป็นเวลา 60+ นาที เพื่อให้เอนไซม์ในมอลต์เปลี่ยนแป้งเป็นน้ำตาล
- น้ำหวานจากการแมชชิ่ง เรียกว่า น้ำเวิร์ท (Wort)
- หลังจากแมชชิ่งเสร็จ เราจะแยกกากมอลต์ออกจากน้ำเวิร์ท และใช้น้ำร้อนล้างกากมอลต์ เพื่อเอาน้ำตาลที่ติตอยู่ในกากมอลต์ออกมา

**บอยลิ่ง (Boiling)**
- เราจะต้มเวิร์ดให้เดือด เพื่อต้มเพื่อฆ่าเชื้อและขจัดกลิ่นอับจากมอล์ต เป็นเวลา 60 นาที
- ขั้นตอนนี้ เราจะนับเวลาถอยหลัง ถ้าเราต้ม 60 นาที เริ่มเดือดนับนาทีที่ 60 จนถึงต้มเสร็จ นาทีที่ 0
- ระหว่างบอยลิ่ง เราสามารถใส่ฮอปส์ได้ ฮอปส์จะเพิ่มความขมและเพิ่มกลิ่นหอม
- ฮอปส์จะเพิ่มความขม ตามเวลาที่โดนความร้อน ยิ่งนานยิ่งขมมาก การเพิ่มความขมจึงนิยมใส่นาทีที่ 60-30 นาที
- ฮอปส์จะเพิ่มกลิ่นหอม เป็นน้ำมันหอมระเหย จะหายไปเมื่อโดนความร้อน ยิ่งนานยิ่งความหอมยิ่งหายไป นิยมใส่นาทีที่ 30-0
- ในสูตรจะมีระบุว่าใส่ฮอปส์ จำนวนเท่าไหร่ ที่นาทีที่เท่าไหร่ เช่น ใส่ฮอปส์ 20 กรัม ในนาที่ที่ 10

**คูลลิ่ง (Cooling)**
- เมื่อถึงนาทีที่ 0 เราจะหยุดให้ความร้อน และพยายามลดอุณหภูมิของเวิร์ท โดยเร็วที่สุดเท่าที่เป็นไปได้
- เราคูลลิ่งเพื่อให้อุณหภูมิของเวิร์ท พร้อมให้ยีสต์เริ่มทำงาน โดยทั่วไปจะอยู่ที่ 18-22 องศา
- การที่เรารีบลดอุณหภูมิ เพราะที่อุณหภูมิ 35-45 องศาเป็นอุณหภูมิที่เหมาะกับเชื้อแบคทีเรียเจริญเติบโต ถ้าอยู้ในช่วงนี้นานงอาจทำให้เบียร์ออกมาเสียได้
- หลังจากอุณหภูมิต่ำกว่า 90 องศา ทุกอย่างที่สัมผัสกับน้ำเวิร์ทจะต้องฆ่าเชื้อทั้งหมด

**เฟอเมนท์ (Ferment)**
- หลังจากเราคูลลิ่ง จนได้อุณหภูมิที่ต้องการแล้ว เราจะถ่ายเวิร์ทลงถังหมัก และเติมยีสต์ เพื่อเริ่มกระบวรการหมัก
- ถังหมักควรมีการควมคุมอุณหภูมิให้เหมาะกับยีสต์ ตลอดช่วงเวลาที่หมัก
- ระยะเวลาการหมักขึ้นกับยีสต์ และอุณหภูมิที่ใช้หมัก โดยทั้วไปจะอยู่ที่ 7-14 วัน
- ที่ซองยีสต์จะมีบอกช่วงอุณหภูมิที่ยีสต์ทำงาน ไม่ควรหมักอุณหภูมิที่สูงกว่าที่ระบุ เพราะยีสต์บางชนิดอาจผลิตแอลกอฮอล์ที่เป็นพิษได้


#### Recommend Beginner Setup
- Hot Side: Brewzilla
- Cold Side: Fermzilla, 2hnd Keg, bucket blaster,  refrigerator, CO2 Set
